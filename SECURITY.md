# 安全政策

## 支持的版本

[GitHub Releases](https://github.com/Ivan494/trad-simp/releases) 上的最新版本为当前支持版本。

## 报告漏洞

本程序会注册全局快捷键，并向当前焦点窗口注入复制/粘贴。若发现安全问题，请通过 GitHub 个人资料中的联系方式私信维护者，或在 GitHub 上提交私密安全公告（如可用）。

请勿针对尚未修复的漏洞开公开 Issue。

---

## English

The latest release on [GitHub Releases](https://github.com/Ivan494/trad-simp/releases) is supported.

This app registers a global hotkey and injects copy/paste into the focused window. Report security issues privately via the maintainer contact on the GitHub profile, or open a private security advisory on GitHub if available.

Do not open a public issue for unpatched vulnerabilities.
