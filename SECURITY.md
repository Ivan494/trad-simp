# Security Policy

## Supported versions

The latest release on [GitHub Releases](https://github.com/Ivan494/trad-simp/releases) is supported.

## Reporting a vulnerability

This app registers a global hotkey and injects copy/paste into the focused window. Please report security issues privately by emailing the maintainer listed on the GitHub profile, or open a private security advisory on GitHub if available.

Do not open a public issue for unpatched vulnerabilities.
